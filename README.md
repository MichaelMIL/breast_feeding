# Feeding Tracker

A progressive web app (PWA) for tracking breastfeeding sessions, pumping, diaper changes, and medications.

**Current Version: v1.16**

## Features

- **Nursing & Pumping** — Log left/right breast nursing sessions and pump sessions with timestamps. Nursing starts a countdown timer; pumping is logged separately without affecting the timer.
- **Medication Reminders** — Track medications with configurable intervals. Alerts when a dose is due. Default medications: Ibuprofen (8h), Acamol (6h), Optalgin (6h).
- **Diaper Tracking** — Log pee, poop, or both with optional custom time.
- **Unified History** — All events (feeds, pumps, diapers, medications) shown in a single timeline on the tracker tab.
- **Statistics** — Session counts, left/right split, feed/pump split, 7-day charts, diaper breakdown.
- **Night Mode** — Dark warm theme, enabled by default.
- **Hebrew Support** — Switch between English and Hebrew (RTL) via settings.
- **Screen Wake Lock** — Keeps the screen on while tracking.
- **Audio Alerts** — 3-note chime + screen flash + vibration when timer expires.
- **Data Export** — Export all feeding data as CSV from the Stats page.
- **Offline Support** — Runs fully offline via localStorage.

## Usage

Open `index.html` in a browser, or visit the GitHub Pages deployment.
